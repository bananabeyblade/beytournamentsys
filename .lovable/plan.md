## 目標

把賽程樹狀圖改成參考圖那種傳統對稱式 bracket：左右兩側往中間收斂、每場卡片緊湊只有兩列選手、卡片之間用括號狀連接線相連、每位選手左側顯示種子序號、輪次標題橫向排在最上方、決賽置中並加強調。

## 目前狀況

`src/components/BracketTab.tsx` 用 flex 欄位 + `justify-around` 排列，沒有連接線、沒有種子序、卡片較高（含狀態列與提示文字），只有超過 32 人時才左右分佈。

## 要做的事（純顯示層，不動賽事邏輯／資料／後端）

1. **精準定位取代 justify-around**
   - 每輪卡片改用絕對定位計算 y 座標：第 0 輪等距排列，第 r 輪每張卡置於其兩個來源卡的中點。這是畫出正確連接線的前提。
   - 欄寬、卡高、垂直間距抽成常數，手機用較小值、`sm:` 以上放大。

2. **連接線**
   - 在每欄之間插入一個窄的連接線層，用絕對定位的 CSS 邊框（水平段 + 垂直段，形成括號）連接兩張來源卡到下一輪卡片。右半側鏡像方向。
   - 線條使用 `border-border` / 已完成場次用 `border-primary/50`，不寫死顏色。

3. **緊湊卡片**
   - `BracketMatchCard` 改為兩列式：每列＝種子號（取自 `players` 的 `seed`）＋ 選手名（truncate）＋ 分數。
   - 狀態（比賽中／已完成／待開始）改成細邊框顏色 + 右上小標記，移除「點擊查看比賽歷程」整行文字改為 hover/aria 提示，維持點擊開啟歷程。
   - 保留「我的比賽」高亮 ring 與 (我) 標記，縮小成 icon + 邊框強調。

4. **對稱布局**
   - 一律採左右對稱（不再只在 >32 人時），決賽置中並加金色／primary 強調樣式，左右兩側輪次標題各自顯示。
   - 人數少（例如 ≤8 人）時仍可正確對半分，只有 1 輪時退回單側顯示。

5. **手機可用性**
   - 沿用現有 `usePanZoom`（拖曳／雙指縮放／雙擊），初始 zoom 依內容寬度自動 fit 到 viewport，讓手機一開啟就看得到整張圖。
   - 保持先前修好的殘影對策（穩定 will-change、不使用 content-visibility）。

## 驗證

用 Playwright 在 390x844 與桌機寬度各截圖，檢查：連接線對齊卡片中心、決賽置中、拖曳後無殘影、我的比賽仍高亮。

不更動 `tournament-store`、資料表或任何賽事邏輯。
