# 修正報名與核准流程的 bug

只做程式修正，不改資料庫結構。

## 已確認的問題與修正

1. **核准報名可能重複加入同一位選手**
   目前核准時會先把該筆從待審清單移除，再呼叫刪除。若刪除失敗（網路瞬斷），下一次同步會把同一筆拉回來，裁判再按一次就會出現兩個同名選手。
   → 改成「刪除成功後才加入名單」，失敗時保留該筆並提示重試，不會重複加入。

2. **沒有批次核准，64 人要按 64 次**
   每按一次核准都會觸發一次完整賽事狀態上傳（含所有選手），連續 64 次在現場網路容易卡頓。
   → 新增「全部核准」按鈕，一次合併成單次名單更新與單次上傳；同時避免同名重複進入名單。

3. **待審清單的即時訂閱沒有限定賽事也沒有節流**
   訂閱整張報名表，任何一筆新增都重新抓完整清單；多人同時掃碼時裁判裝置會被觸發數十次重複查詢。
   → 訂閱只限定當前賽事，並加上約 1 秒的節流合併連續事件。

4. **等待開賽畫面輪詢過於頻繁**
   `/register` 等待畫面每 5 秒輪詢一次，且同時已有即時訂閱。
   → 放寬到 20 秒，開賽仍由即時訂閱立即跳轉。
